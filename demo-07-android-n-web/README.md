# Demo 07: Android and Web

## Android

Plug the device with a USB cable, turn ON USB debugging then run `scrcpy`.
Open file browser to dota.glb, select F3D.
Play animation, show scene hierarchy, option panels and console

## Web

- Go to https://f3d.app/viewer and make a quick demo
- PREP: run `npm install`
- Examples:
  - npm run dev --workspace volume-rendering
  - npm run dev --workspace gaussian-splatting
